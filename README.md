# aahutispace.

A pastel editorial personal blog about psychology, brains, human behaviour and thoughts.

## Publish with GitHub Pages

1. Create a **public** GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. After GitHub publishes it, add your custom domain under **Settings → Pages → Custom domain**.
7. At your domain registrar, add the DNS records GitHub provides.

This version is a static site, so it does not need a paid server or database.
